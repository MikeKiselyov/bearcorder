The screen recorder and toolbox for your Mac.

A macOS menu bar app. The last minutes of your screen are always kept, so whatever you just saw, a bug or a moment you want to show, is already on video. Next to it: screenshots with markup, a video editor, bug reports with steps, layout checks, a dev toolbox and disk clean-up.

To install, open Terminal and paste (macOS 14 or later):

curl -fsSL https://raw.githubusercontent.com/MikeKiselyov/bearcorder/main/scripts/install.sh | bash
All features Free and open source (MIT), no account. Source on GitHub.

Catch what already happened

Bearcorder keeps the last 1 to 5 minutes of the screen on disk. Press ⌥⇧1 for the last 30 seconds or ⌥⇧2 for the last minute, and the clip opens in the video editor.

Clicks and keys come with the clip and turn into steps. When an app crashes, the minute before it is saved with the crash report.

Mark up and report

Arrows, boxes, blur, labels and numbered steps on screenshots. Crop, trim and marks on video.

Copy bug report puts steps, expected and actual result and the environment on the clipboard, in Markdown or Jira wiki.

Tools you use daily

The dev toolbox opens with ⌥⇧D on what is on the clipboard and picks the right tool.

  • JSON
  • JSON diff
  • XML and YAML
  • JWT
  • Base64 and URL
  • Unix time
  • Cron
  • Time zones
  • Test data
  • Regex
  • UUID
  • Hashes
  • QR codes

Layout checks

Resize the window you test to desktop, tablet or phone sizes. Measure on the screen in points and pixels.

Pick a color and check contrast. Float a design export over the app, with opacity and click-through.

Space

See what builds and tests left on the disk: Xcode data and simulators, npm, Gradle, Homebrew, pip and other caches.

Tick what goes and see the size before anything is removed. Project folders go to the Trash, and folders tracked by git are left out.

How it differs

  • Everything runs on your Mac. Nothing is uploaded, and there is no account.
  • It is free, and the app is built on your Mac from the source on GitHub.
  • The last minutes are always kept, so you do not have to start recording before the bug.
  • It is made for testing: bug reports with steps, expected and actual result, layout checks and test data in one app.
